# Богемия 1403

Неофициальная энциклопедия эпохи и мест Kingdom Come: Deliverance II: Богемия 1403 года, история и вымысел игры, карта, хронология, глоссарий, травник и музыка.

Сайт: https://rastaskin.github.io/kcd2-encyclopedia/

Статический сайт без сборки: `index.html` + `assets/` + `data/` + `img/`. Открывается и локально двойным кликом по `index.html`.
